# Required Skills

- **J2EE platform fundamentals** — understanding of WAR/EAR packaging, Maven builds and dependency management (pom.xml), and deployment to a Java application server
- **Java Servlets** — proficient with the servlets, servlet lifecycle, request/response handling
- **SQL proficiency (Db2)** — able to read and trace moderately complex SQL to understand exactly what data a legacy query retrieves
- **REST API consumption from Java** — hands-on experience issuing REST calls (RestTemplate or HttpClient) and handling token-based authentication (OAuth2 client credentials flow: gateway URL, client ID/secret, scope)
- **Document/binary streaming over REST** — experience with InputStream/OutputStream handling, multipart uploads, and chunked transfer, since document content is streamed rather than returned as a simple JSON payload
- **Legacy code comprehension** — able to read unfamiliar, often undocumented code and accurately reconstruct its intended behavior before changing anything
- **Git-based version control workflow**

## Preferred / Nice to Have

- Prior hands-on experience with IBM Content Manager, or a comparable Content management system
- Spring / Spring Boot experience (useful both for consuming the target APIs and for occasionally contributing to them when a gap is found)
