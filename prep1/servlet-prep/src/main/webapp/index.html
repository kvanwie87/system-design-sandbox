Servlet Prep — Day 1

Deployed WAR is working. Two servlets are available:

/hello — HelloServlet

Responds to GET and POST. Try:

GET  /servlet-prep/hello
GET  /servlet-prep/hello?name=Priya

/echo — JsonEchoServlet

POST JSON, get JSON back. Try from a terminal:

curl -i -X POST http://localhost:8080/servlet-prep/echo \
     -H "Content-Type: application/json" \
     -d '{"message":"hello"}'
